# POME QUESTURE — Premium

Buka `POME-QUESTURE-Premium.html` menggunakan Chrome atau Edge. Sambungan internet diperlukan untuk gaya Tailwind, fon, ikon dan model pengesanan AI.

1. Masukkan nama dan kelas, kemudian pilih karakter.
2. Pilih **Klik / papan kekunci** atau **Gesture AI**.
3. Lengkapkan 5 soalan bagi setiap dua peringkat pertama, kemudian dua misi padanan.
4. Muat turun sijil PNG dan buka **Semakan keputusan anda** untuk mengulang kaji.

## Kawalan

- **A, B, C, D:** pilih jawapan. **Enter:** teruskan selepas menjawab (apabila fokus bukan pada butang lain).
- **Esc:** tutup panel yang terbuka.
- **Tangan:** 1–4 jari untuk A–D; 5 jari untuk soalan seterusnya dalam peringkat pertama. Turunkan jari sebelum memilih semula.
- **Wajah:** kiri A, kanan B, atas C, bawah D. Kembali ke posisi neutral sebelum pilihan berikutnya; gunakan **Set Tengah Wajah** untuk kalibrasi.
- **Padanan:** seret kad ke stesen pada desktop, atau pilih kad kemudian pilih stesen pada telefon.
- **Simpan & keluar:** simpan kemajuan pada pelayar ini. Pilih **Sambung misi tersimpan** untuk meneruskan.

## Penambahbaikan

Paparan makmal hijau premium, model loji interaktif, jejak kemajuan misi, kawalan papan kekunci, seret dan lepas, simpan/sambung permainan, rekod markah pada pelayar, semakan jawapan dan sijil baharu. Markah dikunci selepas setiap jawapan; pertukaran peringkat bebas yang membolehkan pengumpulan markah berulang telah dikeluarkan.

## Kamera dan simpanan

Gesture memerlukan kebenaran kamera dan internet untuk memuatkan model MediaPipe. Jika pelayar mengehadkan kamera apabila fail dibuka terus, gunakan hos localhost atau HTTPS. Pilihan klik tetap tersedia apabila kamera atau model AI gagal. Pemprosesan kamera menggunakan MediaPipe dalam pelayar; kod aplikasi ini tidak menambah perkhidmatan muat naik rakaman.

Versi terkini mempunyai panel **Semakan kamera peranti** di bawah pilihan mod dan dalam panel ujian kamera. Ia memaparkan protokol halaman, konteks selamat, ketersediaan API kamera, status stream/model dan ralat terakhir. Membuka panel semakan sahaja tidak meminta akses kamera. Ketersediaan API bukan bukti bahawa kamera fizikal atau pengesanan AI sudah berfungsi. Fail tempatan boleh diterima oleh sesetengah pelayar, tetapi akses kamera tidak dijamin pada semua pembuka fail Android/iPad. Ujian simulasi konteks tidak selamat, API tiada dan kebenaran ditolak telah lulus; pengujian fizikal Android/iPad masih belum dilakukan.

Kemajuan dan lapan rekod markah terbaik disimpan dalam storan pelayar, bergantung pada kebenaran storan. Ia tidak disegerakkan ke peranti lain dan boleh hilang apabila data pelayar dikosongkan. Foto sijil tidak dimasukkan ke storan kemajuan.

## Pengesahan

Ujian automatik Edge berjaya menamatkan permainan dengan **140/140**, menguji klik dan seret/lepas, kunci jawapan, bantuan 50:50, simpan/sambung termasuk padanan separuh siap, tetapan semula permainan, kalkulator, muat turun sijil, keselamatan paparan nama, respons apabila kamera ditolak, dan ketiadaan limpahan mendatar pada desktop serta telefon selebar 390px. Tiada ralat JavaScript halaman dikesan dalam ujian tersebut.

Kamera fizikal, ketepatan gesture sebenar dan Safari/iPad belum diuji. Kandungan asal dikekalkan sebagai bahan pembelajaran; nilai loji dan impak dipaparkan sebagai ilustrasi konsep, bukan pengesahan prestasi atau pematuhan industri.
